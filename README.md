# EcoPulse

A CHE-110 team project presenting climate information and digital technologies related to monitoring climate change and responding to it.

## What it includes
- Climate indicators and source-linked data visualizations
- Examples of digital climate solutions
- A comparison of CO₂ emissions by region
- An interactive renewable-energy scenario

## Technologies and tools
HTML, CSS, JavaScript, Git and GitHub

## My contribution
I built the website for our CHE-110 team project, including its interactive sections.
